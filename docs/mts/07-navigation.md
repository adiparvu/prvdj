# 7. Navigation

Governed by Master Prompt #2. Status: **Not started** — Phase 1.

## Decisions already fixed

- **Six primary spaces**: Home, Library, AI Studio, Mix Editor, Live Performance,
  Settings.
- **Adaptive by size class, not by device**: bottom bar in compact width, sidebar
  in regular width, sidebar with inspector on the desktop. One information
  architecture, three presentations — never three separate interfaces.
- **No hamburger menus, no deep hierarchies.** Master Prompt #15 requires every
  interaction to answer what is happening and whether it can be undone; a menu
  that hides destinations answers neither.
- **Five expertise modes are not five interfaces.** Beginner through Expert
  (Master Prompt #25) change vocabulary, automation level and which controls are
  visible. They are progressive disclosure over one component set. Building them
  as separate screens would multiply the surface by five and violate the
  anti-duplication rule of Master Prompt #17.
